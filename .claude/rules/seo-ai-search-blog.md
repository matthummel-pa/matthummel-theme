## This repository (do not ignore)

This is Matt Hummel’s Sage 11 theme. Blog drafts become WordPress posts (block editor HTML), not Blade chrome.

- **Voice:** first-person **I / my**. Glossary: shops, agencies, developers, learners (`content.md`).

- **Ship path:** draft in Markdown for review; convert to post HTML with language classes on `<code>` for highlight.js. Prefer publishing the Article JSON-LD snippet only when Matt asks to ship schema on that post (Rank Math may already own Article markup).
